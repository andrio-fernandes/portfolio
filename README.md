## 📌 Overview

This project is my personal developer portfolio designed to present my projects, frontend skills, and contact information in a clean and responsive interface.

The portfolio includes a modern glassmorphism UI, responsive layout, project showcase section, and a contact form connected to a backend server with MongoDB integration.

The frontend is deployed using GitHub Pages and the backend API is deployed using Render.
